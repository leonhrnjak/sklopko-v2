Run and edit, softly (mockup)

No hard modes. The run controls are always in the toolbar, and the edit tools are always on the canvas. Whichever side you are using is full strength and the other is quieter. A lock, off by default, can switch editing off while the simulation runs. The buttons work: run, pause, lock, change the speed, click the wire between the AND gate and the LED.
